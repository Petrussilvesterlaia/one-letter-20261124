One letter for one day: U, for a day that came unhinged — every plan
slipping off its hinges until the whole day was swinging free. The
program writes exactly that one letter to `/output/entry.txt`, nothing
else: no word, no gloss, no punctuation.

## Run it

```sh
python3 main.py
```
